🔍 GitHub Commit Explorer

Ein kleines Python-Tool, das öffentliche GitHub-Profile durchsucht und alle Commits der Repositories auflistet! 🐙💻
✨ Features

    📂 Ruft automatisch alle öffentlichen Repos eines GitHub-Users ab
    📝 Listet für jedes Repo sämtliche Commits auf
    🔑 Zeigt Commit-SHA und die E-Mail-Adresse des Autors an
    ⚠️ Robuste Fehlerbehandlung bei Verbindungsproblemen oder fehlgeschlagenen API-Requests

🛠️ Verwendung

    Skript starten
    GitHub-Usernamen eingeben
    Alle Repos & Commits werden automatisch durchsucht und ausgegeben ✅

📦 Technologien

    Python 🐍
    GitHub REST API
    requests Bibliothek
